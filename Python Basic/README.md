# Python Geometry & Financial Calculations

A dedicated repository section tracking my early practice in mastering Python's standard input/output operations, data type conversions, and arithmetic evaluations. This collection focuses on implementing standard mathematical formulas to solve geometric problems and compute financial interest, building a foundational understanding of variables, operators, and expression evaluation.

## 🚀 Overview
This module covers basic sequential programming in Python. The scripts demonstrate how to capture user input, convert string data into workable numerical types (`int`, `float`), and apply standard mathematical operators to compute dynamic results. The logic progresses from simple linear equations to more complex evaluations involving fractional exponents and rounding functions.

## 🛠️ Tech Stack & Tools
* **Language:** Python 3
* **Core Concepts:** Standard I/O (`input()`, `print()`), Explicit Type Casting (`float()`, `int()`), Arithmetic Operators (`+`, `-`, `*`, `/`, `**`), Order of Operations, Built-in Functions (`round()`)

## 📂 File Index & Structure

### Geometric Calculations
* `AreaOfRightAngledTriangle.py`: Calculates the area of a right-angled triangle by taking the base and height as floating-point inputs and applying the standard base times height divided by two formula.
* `AreaOfTriangle.py`: Computes both the area and perimeter of a generic triangle using the lengths of its three sides. It implements Heron's formula, utilizing the `** 0.5` exponentiation method to calculate the square root of the semi-perimeter product.

### Financial Calculations
* `SimpleInterest.py`: Takes principal, rate, and time as integer inputs to calculate the accrued simple interest and the total final amount.
* `CompoundInterest.py`: Implements the compound interest formula to calculate exponential growth over time. Uses floating-point inputs and the `round()` function to cleanly format the resulting financial figures to two decimal places.

## 💡 Key Learnings & Features
* **Data Type Casting:** Understanding the necessity of wrapping standard string `input()` calls with `int()` or `float()` to enable mathematical operations on user-provided data.
* **Mathematical Operators:** Practical application of Python's arithmetic operators, particularly the exponentiation operator (`**`), used here for both power calculations (compound interest time compounding) and square roots (Heron's formula).
* **Precision & Formatting:** Using Python's built-in `round()` function to handle floating-point arithmetic precision, ensuring financial and geometric outputs are readable.
* **Translating Formulas to Code:** Successfully converting standard algebraic equations into linear, executable Python syntax while respecting the order of operations.
