# Python Control Flow & Conditional Logic

A dedicated repository section tracking my progression into Python's control flow mechanisms. This collection focuses on decision-making structures, execution branching, and conditional logic, which are essential for building dynamic, responsive programs and complex algorithms.

## 🚀 Overview
This module covers the implementation of conditional statements in Python. The scripts demonstrate how to control program execution flow using boolean evaluations, ranging from simple binary decisions to complex, chained, and nested conditional structures.

## 🛠️ Tech Stack & Tools
* **Language:** Python 3
* **Core Concepts:** Boolean Logic, Execution Branching, Indentation (Scope), Comparison Operators (`>=`, `<=`, `==`), Modulo Arithmetic (`%`), Chained Comparisons
* **Keywords & Syntax:** `if`, `elif`, `else`, Ternary Operator (`... if ... else ...`)

## 📂 File Index & Structure

### Basic Branching & Logic
* `IfElseStatement.py`: Introduces fundamental `if` and `if-else` blocks. Demonstrates age-based eligibility checks and mathematical evaluations like identifying odd/even numbers (using modulo `%`) and positive/negative integers.

### Complex & Nested Conditions
* `IfElseIfStatement.py`: Implements an `if-elif-else` ladder to handle multiple distinct conditions. Showcases Python's elegant chained comparison syntax (e.g., `90 <= marks <= 100`) to evaluate grading tiers.
* `NestedIf.py`: Explores nested conditional logic by placing `if-elif` structures inside an outer `if` block. Demonstrates hierarchical decision-making (e.g., first verifying a passing score, then determining the specific letter grade).

### Inline Evaluations
* `TernaryOperator.py`: Highlights Python's concise ternary operator syntax (`[on_true] if [expression] else [on_false]`), allowing for single-line conditional evaluations to write cleaner, more compact code.

## 💡 Key Learnings & Features
* **Indentation as Syntax:** Understanding that unlike languages that use curly braces, Python relies strictly on indentation to define the scope of conditional blocks.
* **Chained Comparisons:** Leveraging Python's unique ability to chain relational operators (e.g., `a < b < c`), making range evaluations much cleaner than using multiple logical `and` operators.
* **Hierarchical Logic:** Mastering the difference between sequential `if` statements (where all conditions are checked) versus `if-elif` ladders (where execution stops at the first true condition) and nested structures for layered decision-making.
* **Code Brevity:** Utilizing the ternary operator to write cleaner, more Pythonic code for simple binary decisions, reducing vertical code bloat.
